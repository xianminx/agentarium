A table that knows how accurate it is.

Every AI column carries a measured accuracy, a version number, and the right to say “not enough evidence” instead of guessing. The number comes from one place: the corrections reviewers make to its own output. Run a column, review a few cells, then replay a candidate version against everything you’ve confirmed.

Interactive prototype for the Agentic Table research in plans/agentic-table/. Companies, runs and source quotes are invented for the demo; agent runs are simulated on a timer, not real research. The mechanism on show — abstention, cell-level evidence, corrections feeding a golden set, and version replay gated on that set — is the part the PRD specifies.
